# RedUser-P — By Prem

A native Android starter app for an authorized-use cybersecurity toolkit. UI theme: black + red. Languages: English + Hindi.

## Included in this MVP
- Local password-strength audit (password stays on device)
- SHA-256 hash generator
- DNS lookup for domains you are authorized to inspect
- Basic security checklist
- Official phone-recovery guidance
- Legal-use/about screen

## Not included
No account cracking, credential theft, lock-screen bypass, unauthorized access, exploit automation, or data extraction. For locked phones, use the manufacturer's official recovery process and authorized service channels.

## Build the APK
1. Install the latest stable Android Studio.
2. Open this `RedUser-P` folder in Android Studio.
3. Allow Gradle sync and install the Android SDK Platform 35 if prompted.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location (usually `app/build/outputs/apk/debug/app-debug.apk`).
